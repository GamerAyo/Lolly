#  Candy – Golden carrots
Make your golden carrots into candy!

**Candy – Golden carrots** is a small, resource packs for minecraft that turns Golden Carrots into candy when renamed.

## ✨ Features

- **Custom Candy Texture:** The Golden carrot's appearance is changed into one of the 3 candy colors.
- **Multiple Name Variations:** Supports different names to get different color of candy.
- **Vanilla Friendly:** Regular Golden Carrots keep their original appearance.

## 🎮 Instructions

1. Install and enable the resource pack.
2. Obtain a Golden Carrot.
3. Rename it using an anvil to one of the supported names:
   - “Lolly” for a blue candy.
   - “Lollie” for a green candy.
   - “Candy” for a purple candy.
4. Enjoy the new candy texture!

## 📌 Compatibility

- **Edition:** Minecraft Java Edition
- **Type:** Resource Pack
- **Requirements:** No additional mods required.
